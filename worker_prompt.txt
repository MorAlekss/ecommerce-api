## What to change
MIGRATION PATTERN (apply to every function):

**Imports:**
```python
# BEFORE
import requests

# AFTER
import httpx
```

**Sync → Async function signatures:**
```python
# BEFORE
def get(url, params=None, headers=None):
    response = requests.get(url, params=params, headers=headers)
    response.raise_for_status()
    return response.json()

# AFTER
async def get(url, params=None, headers=None):
    async with httpx.AsyncClient() as client:
        response = await client.get(url, params=params, headers=headers)
        response.raise_for_status()
        return response.json()
```

**For functions that call `requests.request(method, ...)`:**
```python
# BEFORE
response = requests.request(method, url, **kwargs)

# AFTER
async with httpx.AsyncClient() as client:
    response = await client.request(method, url, **kwargs)
```

**Exception handling (if any):**
```python
# BEFORE
except requests.exceptions.RequestException

# AFTER
except httpx.RequestError
```

**Key rules:**
1. EVERY function that uses requests must become `async def`
2. EVERY requests call must use `async with httpx.AsyncClient() as client:`
3. EVERY client method call must use `await`
4. `response.raise_for_status()`, `.json()`, `.status_code` remain the same (httpx has same API)
5. Do NOT change function signatures beyond adding `async`
