## What to change
Migrate from sync `requests` to async `httpx.AsyncClient()`.

Source file pattern (BEFORE):
```python
import requests
from src.config import API_BASE_URL

def list_users(token, page=1, limit=20, filters=None):
    headers = {"Authorization": f"Bearer {token}"}
    params = {"page": page, "limit": limit, **(filters or {})}
    response = requests.get(f"{API_BASE_URL}/admin/users", params=params, headers=headers)
    response.raise_for_status()
    return response.json()
```

Target pattern (AFTER):
```python
import httpx
from src.config import API_BASE_URL

async def list_users(token, page=1, limit=20, filters=None):
    headers = {"Authorization": f"Bearer {token}"}
    params = {"page": page, "limit": limit, **(filters or {})}
    async with httpx.AsyncClient() as client:
        response = await client.get(f"{API_BASE_URL}/admin/users", params=params, headers=headers)
        response.raise_for_status()
        return response.json()
```

Apply this to ALL 4 functions: list_users, get_user, suspend_user, reinstate_user.
- suspend_user uses POST with json={"reason": reason}
- reinstate_user uses DELETE and returns `response.status_code`
