## What to change
MIGRATION PATTERN (apply to every function in every file):

**Imports (in each source file):**
```python
# BEFORE
import requests
from src.config import API_BASE_URL

# AFTER
import httpx
from src.config import API_BASE_URL
```

**Every function becomes async with httpx.AsyncClient:**
```python
# BEFORE
def get_profile(user_id, token):
    headers = {"Authorization": f"Bearer {token}"}
    response = requests.get(f"{API_BASE_URL}/users/{user_id}", headers=headers)
    response.raise_for_status()
    return response.json()

# AFTER
async def get_profile(user_id, token):
    headers = {"Authorization": f"Bearer {token}"}
    async with httpx.AsyncClient() as client:
        response = await client.get(f"{API_BASE_URL}/users/{user_id}", headers=headers)
        response.raise_for_status()
        return response.json()
```

**Apply this pattern to ALL functions in ALL 3 source files:**
- profile.py: get_profile, update_profile, update_avatar, delete_account
- preferences.py: get_preferences, update_preferences, reset_preferences
- admin.py: list_users, get_user, suspend_user, reinstate_user

**For tests (test_users.py), update mock patches:**
```python
# BEFORE
with patch('src.users.profile.requests.get') as mock_get:

# AFTER  
with patch('src.users.profile.httpx.AsyncClient') as mock_client_cls:
    mock_client = mock_client_cls.return_value.__aenter__.return_value
    mock_response = MagicMock()
    mock_response.json.return_value = {"id": "u1", "name": "Alice"}
    mock_response.raise_for_status.return_value = None

```
