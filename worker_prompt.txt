## What to change

Pattern: `import requests` → `import httpx`
Pattern: `def get(url, ...)` → `async def get(url, ...)`

Pattern: `response.json()` stays the same, `response.raise_for_status()` stays the same.

Keep the same function signatures but add `async` keyword. Each function should create its own AsyncClient context manager.
