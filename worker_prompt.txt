## What to change
Migrate from sync `requests` to async `httpx.AsyncClient()`.

Source file pattern (BEFORE):
```python
import requests
def get(url, params=None, headers=None):
    merged_headers = {**DEFAULT_HEADERS, **(headers or {})}
    response = requests.get(url, params=params, headers=merged_headers)
    response.raise_for_status()
    return response.json()
```

Target pattern (AFTER):
```python
import httpx
async def get(url, params=None, headers=None):
    merged_headers = {**DEFAULT_HEADERS, **(headers or {})}
    async with httpx.AsyncClient() as client:
        response = await client.get(url, params=params, headers=merged_headers)
        response.raise_for_status()
        return response.json()
```

Apply this to ALL 5 functions: get, post, put, patch, delete.
For delete: it returns `response.status_code` (not .json()).

Test file pattern: change tests from sync to async. Use `pytest.mark.asyncio` decorator.
Mock `httpx.AsyncClient` instead of `requests.get/post`.
Example test pattern (AFTER):
```python

@pytest.mark.asyncio
async def test_get():
    mock_response = MagicMock()
    mock_response.json.return_value = {"data": "value"}
    mock_response.raise_for_status.return_value = None
    mock_client = AsyncMock()

        assert result["data"] == "value"
```
