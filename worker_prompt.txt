## What to change
The integration test patches `requests` on modules that have ALREADY been migrated to httpx async (src/auth/login.py, src/products/catalog.py, src/orders/checkout.py, src/payments/stripe.py). The test currently fails because it tries to patch `requests` on modules that no longer import `requests`.

Key changes:
1. The test must become `async def` and use `@pytest.mark.asyncio` decorator
2. Import pytest and AsyncMock
3. Replace ALL `patch('module.requests')` with `patch('module.httpx.AsyncClient')`
4. Mock the AsyncClient context manager and await pattern
5. All function calls inside the test must use `await`

The modules being patched:
- `src.auth.login` — already uses httpx async
- `src.products.catalog` — already uses httpx async
- `src.orders.checkout` — already uses httpx async
- `src.payments.stripe` — already uses httpx async

Example before:
```python
with patch('src.auth.login.requests') as mock_requests_login, \
     patch('src.products.catalog.requests') as mock_requests_catalog, \
     ...
    mock_requests_login.post.return_value = login_resp
    from src.auth.login import login
    auth = login("user@example.com", "password")
```

Example after:
```python
@pytest.mark.asyncio
async def test_full_purchase_flow():
    with patch('src.auth.login.httpx.AsyncClient') as mock_client_cls_login, \
         patch('src.products.catalog.httpx.AsyncClient') as mock_client_cls_catalog, \
         ...
        mock_login_client = AsyncMock()
        mock_login_client.post.return_value = login_resp
        mock_client_cls_login.return_value.__aenter__.return_value = mock_login_client
        ...
        from src.auth.login import login
        auth = await login("user@example.com", "password")
```
