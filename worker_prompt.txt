## What to change
Migrate from sync `requests` to async `httpx.AsyncClient()`.

Source file pattern (BEFORE):
```python
import requests
import logging

logger = logging.getLogger(__name__)

def log_request(method, url, **kwargs):
    logger.info(f"{method.upper()} {url}")
    response = requests.request(method, url, **kwargs)
    logger.info(f"Response: {response.status_code}")
    return response

def authenticated_get(url, token, params=None):
    headers = {"Authorization": f"Bearer {token}"}
    response = requests.get(url, params=params, headers=headers)
    response.raise_for_status()
    return response.json()
```

Target pattern (AFTER):
```python
import httpx
import logging

logger = logging.getLogger(__name__)

async def log_request(method, url, **kwargs):
    logger.info(f"{method.upper()} {url}")
    async with httpx.AsyncClient() as client:
        response = await client.request(method, url, **kwargs)
        logger.info(f"Response: {response.status_code}")
        return response

async def authenticated_get(url, token, params=None):
    headers = {"Authorization": f"Bearer {token}"}
    async with httpx.AsyncClient() as client:
        response = await client.get(url, params=params, headers=headers)
        response.raise_for_status()
        return response.json()
```

Apply this to ALL 5 functions: log_request, authenticated_get, authenticated_post, authenticated_put, authenticated_delete.
- authenticated_delete returns `response.status_code` (not .json()).

## Codebase conventions
- All async functions use `async with httpx.AsyncClient() as client:` pattern
- Functions that return JSON use `response.json()`
- Functions that return status use `response.status_code`
- `raise_for_status()` is always called after the request
