## What to change
Migrate from sync `requests` to async `httpx.AsyncClient()`.

Source file pattern (BEFORE):
```python
import requests
from src.config import API_BASE_URL

def get_profile(user_id, token):
    headers = {"Authorization": f"Bearer {token}"}
    response = requests.get(f"{API_BASE_URL}/users/{user_id}", headers=headers)
    response.raise_for_status()
    return response.json()
```

Target pattern (AFTER):
```python
import httpx
from src.config import API_BASE_URL

async def get_profile(user_id, token):
    headers = {"Authorization": f"Bearer {token}"}
    async with httpx.AsyncClient() as client:
        response = await client.get(f"{API_BASE_URL}/users/{user_id}", headers=headers)
        response.raise_for_status()
        return response.json()
```

Apply this to ALL 4 functions: get_profile, update_profile, update_avatar, delete_account.
- update_profile uses PUT with json=data
- update_avatar uses PATCH with json={"avatar_url": avatar_url}
- delete_account uses DELETE and returns `response.status_code`

## Codebase conventions
- All async functions use `async with httpx.AsyncClient() as client:` pattern
- See existing httpx async examples in src/auth/login.py, src/products/catalog.py
- Functions that return JSON use `response.json()`
- Functions that return status use `response.status_code`
- `raise_for_status()` is always called after the request
