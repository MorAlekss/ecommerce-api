### What to change

**Import:** `import requests` → `import httpx`

**Every function must become `async def`** and use `httpx.AsyncClient()`:

```python
# BEFORE (sync):
import requests
def get(url, params=None, headers=None):
    response = requests.get(url, params=params, headers=headers)
    response.raise_for_status()
    return response.json()

# AFTER (async):
import httpx
async def get(url, params=None, headers=None):
    async with httpx.AsyncClient() as client:
        response = await client.get(url, params=params, headers=headers)
        response.raise_for_status()
        return response.json()
```

**Exception mapping:**
- `requests.exceptions.RequestException` → `httpx.RequestError`
- `requests.exceptions.HTTPError` → `httpx.HTTPStatusError`

**Delete method returns:** `response.status_code` (same pattern, just async)

**JSON data:** `requests.get/post(..., json=data)` → `httpx client.get/post(..., json=data)` — same parameter name, works identically.

**requirements.txt:** Add `httpx>=0.27.0` alongside existing `requests` line (do NOT remove requests yet — other files may still depend on it).
