## What to change
Pattern: `import requests` → `import httpx`
Pattern: `requests.get(...)` → `async with httpx.AsyncClient() as client: response = await client.get(...)`
Pattern: sync functions → `async def` functions with `await`
Pattern: `response.json()` stays the same, `response.raise_for_status()` stays the same
Pattern: `requests.exceptions.RequestException` → `httpx.HTTPError`
Pattern: `requests.request(method, ...)` → `async with httpx.AsyncClient() as client: await client.request(method, ...)`

For requirements.txt:

- Add: `httpx>=0.27.0`

Example migration for retry.py:
```python
# BEFORE
import time
import requests

def retry_request(func, max_retries=3, backoff=1.0):
    last_error = None
    for attempt in range(max_retries):
        try:
            return func()
        except requests.exceptions.RequestException as e:
            last_error = e
            if attempt < max_retries - 1:
                time.sleep(backoff * (2 ** attempt))
    raise last_error

# AFTER
import time
import httpx

async def retry_request(func, max_retries=3, backoff=1.0):
    last_error = None
    for attempt in range(max_retries):
        try:
            return await func()
        except httpx.HTTPError as e:
            last_error = e
            if attempt < max_retries - 1:
                time.sleep(backoff * (2 ** attempt))
    raise last_error
```
