## What to change
Migration pattern:
- `import requests` → `import httpx`
- Sync functions `def fn(...)` → `async def fn(...)` 
- `requests.get(url, ...)` → `async with httpx.AsyncClient() as client: response = await client.get(url, ...)`
- `requests.post(url, ...)` → `async with httpx.AsyncClient() as client: response = await client.post(url, ...)`
- `requests.put(url, ...)` → `async with httpx.AsyncClient() as client: response = await client.put(url, ...)`
- `requests.patch(url, ...)` → `async with httpx.AsyncClient() as client: response = await client.patch(url, ...)`
- `requests.delete(url, ...)` → `async with httpx.AsyncClient() as client: response = await client.delete(url, ...)`
- `requests.request(method, url, **kwargs)` → `async with httpx.AsyncClient() as client: response = await client.request(method, url, **kwargs)`
- `requests.exceptions.RequestException` → `httpx.HTTPError`

For tests (if in scope):
- Add `import pytest` and `from unittest.mock import patch, AsyncMock, MagicMock`
- Change sync `def test_x():` → `async def test_x():` with `@pytest.mark.asyncio`
- Mock pattern: patch `httpx.AsyncClient` as a context manager with AsyncMock for `__aenter__`/`__aexit__`
- Example mock helper:
```python
def _make_async_client_mock():
    client = AsyncMock()
    cm = MagicMock()
    cm.__aenter__ = AsyncMock(return_value=client)
    cm.__aexit__ = AsyncMock(return_value=None)
    return client, cm
```
- In each test: `client, cm = _make_async_client_mock()`, set `client.get = AsyncMock(return_value=mock_response)`, then `with patch('src.module.httpx.AsyncClient', return_value=cm): result = await fn(...)`
