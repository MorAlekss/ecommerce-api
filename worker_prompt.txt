The source files (src/notifications/email.py, src/notifications/sms.py) are being migrated from sync `requests` to async `httpx`. The test file must be updated to mock `httpx.AsyncClient` instead of `requests`.

Key changes:
1. All tests must become `async def` and use `@pytest.mark.asyncio` decorator
2. Import pytest and AsyncMock from unittest.mock
3. Replace `patch('src.notifications.email.requests.post')` with `patch('src.notifications.email.httpx.AsyncClient')`
4. Replace `patch('src.notifications.sms.requests.post')` with `patch('src.notifications.sms.httpx.AsyncClient')`
5. Mock the AsyncClient context manager: `mock_client_cls.return_value.__aenter__.return_value = mock_client`

The pattern:
```python
import pytest
from unittest.mock import patch, MagicMock, AsyncMock

@pytest.mark.asyncio
async def test_send_email():
    mock_response = MagicMock()
    mock_response.json.return_value = {"id": "msg_123", "status": "queued"}
    mock_response.raise_for_status.return_value = None

    mock_client = AsyncMock()
    mock_client.post.return_value = mock_response

    with patch('src.notifications.email.httpx.AsyncClient') as mock_client_cls:
        mock_client_cls.return_value.__aenter__.return_value = mock_client
        result = await send_email("token123", "user@example.com", "Hello", "Test body")
        assert result["status"] == "queued"
```
